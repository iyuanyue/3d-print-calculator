3D打印计算器 · v1.9.0
应用介绍
一款专业的3D打印成本计算工具，帮助您预估打印项目的各项成本。 其中拓竹p2s和pla、petg的预设是按照本人最新实际购买情况填入的。

主要功能
💰
预估成本计算 材料成本、电力成本、设备折旧精确计算
📊
历史记录 保存和管理所有计算记录
⚡
实时计算 输入参数即时显示计算结果
🎯
智能匹配 打印机型号、耗材类型自动匹配参数
🌗
深浅色主题 跟随系统或手动切换，夜间更护眼
💾
本地存储 数据只保存在浏览器，隐私更安全
更新日志
v1.9.0 2026-11-18
🛡️ 切换机型前会检查参数改动：有改动时弹窗询问「保存并切换 / 不保存 / 取消切换」 📋 弹窗直接列出改了哪些字段和前后值（如 功率 200W → 260W） 💾 选择「保存并切换」会写进该机型的预设，之后切换回来就是你改过的值 🧹 没有改动时不会打扰，直接切换
v1.8.0 2026-11-18
🏷️ 机型支持重命名：同一型号的多台设备可以分别命名（如「车间 P1S」「书房 P1S」） 📄 一键「复制」机型，快速得到一份参数相同的自定义副本 🙈 用不到的预设机型可以「隐藏」，收在列表下方随时恢复，不再挤占机型下拉 🧭 隐藏机型后会自动修正记住的机型选择，不会串到别的机器
v1.7.0 2026-11-18
🗂️ 新增「预设管理」页（底部第三个标签）：打印机与耗材集中管理 ✏️ 机型功率 / 价格 / 寿命、耗材单价都能直接在页面上改，改完自动保存 ➕ 支持新增自定义机型与耗材；预设改过的项可一键「重置」回官方值 🖥️ 桌面端机型行「名称 + 参数」同排显示，一屏看全；手机端分两行更好点
v1.6.0 2026-11-18
🖨️ 自定义机型可「存为机型」：名称与功率/价格/寿命一起保存，出现在机型下拉里 🗂️ 新增「数据与备份」：耗材配置 / 打印机 / 历史记录都可按需勾选导出 📥 导入时只应用勾选的区块；文件缺少所选区块会提示并保持原样 🔀 历史记录导入按时间合并去重，重复导入不会产生重复记录 📦 备份格式升级到 v2，同时兼容 v1 的纯耗材配置文件
v1.5.0 2026-11-18
🧵 支持添加自定义耗材（名称 / 单价 / 颜色），保存在本地并出现在耗材下拉里 📤 配置可导出成 JSON 文件备份，也能导入还原（导入会覆盖当前配置） 🔁 旧版本保存的价格会自动迁移到新的耗材配置里 🧮 自定义耗材同样参与计算，选中后自动带入单价
v1.4.1 2026-11-18
💰 新增「耗材预设价格」：每种耗材的默认单价都可以改，保存后下次选择自动带入 💾 价格保存在本地，刷新、关闭浏览器都不会丢 🏷️ 改过的耗材会标记「已改」，支持一键恢复官方默认价 🧮 修改价格只影响之后的选择，不会改动已保存的历史记录
v1.4.0 2026-11-17
🎯 首页改为「结果优先」布局：顶部常驻打印合计与成本占比 📦 设备参数折叠为一行摘要，点「更改」才展开 🧵 耗材改为紧凑行（类型 / 重量 / 单价 / 小计），点击行展开编辑 ⏱️ 打印时间支持 ±30 分钟步进与 1 / 2 / 4 / 8 小时快捷选择 ↩️ 重置后可「撤销」，一键恢复重置前的全部参数 🖥️ 桌面端右栏合并「成本构成」与「最近记录」
