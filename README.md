# 3D打印计算器

一款专业的3D打印成本计算工具，帮助您精确预估打印项目的各项成本。

![版本](https://img.shields.io/badge/版本-v1.8.0-009688)
![更新日期](https://img.shields.io/badge/更新-2026--11--17-blue)

## ✨ 主要功能

- 💰 **精确成本计算** - 材料成本、电力成本、设备折旧精确计算
- 💵 **耗材与机型可自定义** - 预设单价可改、可加自定义耗材与机型，全部存在本地
- 🗂️ **数据备份** - 耗材 / 打印机 / 历史记录可按需勾选导出与导入
- 📊 **历史记录管理** - 保存和管理所有计算记录
- ⚡ **实时计算** - 输入参数即时显示计算结果
- 📈 **结果优先** - 顶部常驻合计与成本占比，改参数即时看到总价
- 🎯 **智能匹配** - 打印机型号、耗材类型自动匹配参数
- 📱 **响应式设计** - 完美支持电脑端和手机端使用
- 🌗 **深浅色主题** - 跟随系统自动切换，也可手动选择并记忆
- 💾 **离线使用** - 纯前端 + 本地存储，无需网络连接

## 🚀 快速开始

### 在线使用

直接访问：[https://3d.iyuanyue.com](https://3d.iyuanyue.com)

### 本地运行

```bash

git clone https://github.com/iyuanyue/3d-print-calculator.git

# 进入目录
cd 3d-print-calculator

python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```

## 📋 使用说明

1. **选择打印机型号** - 支持多种常见3D打印机；选「其他」并填好参数后可点「存为机型」保存为常用机型
2. **选择耗材类型** - PLA、PETG 等预设（单价可在耗材面板右上角「价格」里修改，也能添加自定义耗材）
3. **输入打印参数** - 重量、时间等，顶部合计条会实时更新
4. **查看计算结果** - 右栏（手机上在下方）显示材料 / 电力 / 折旧明细
5. **保存记录** - 自动保存到历史记录中
6. **备份数据** - 页头数据库图标 →「数据与备份」，勾选耗材 / 打印机 / 历史记录后导出或导入
7. **管理预设** - 底部「管理」标签：改机型功率/价格/寿命、重命名、复制、隐藏用不到的预设，以及新增/删除自定义项

## 🎨 界面与主题

- 统一的浅色 / 深色设计系统（CSS 变量驱动，见 `css/theme.css`）
- 主题按钮三态循环：**跟随系统 → 浅色 → 深色**，选择结果保存在 `localStorage`（键名 `3dpc-theme`）
- 首次访问默认跟随系统；可用 `?theme=light` / `?theme=dark` 临时预览（不写入记忆）
- 桌面端（≥900px）为双栏应用布局：左栏结果优先表单、右栏成本构成与最近记录；手机端为单栏 + 底部标签栏（计算器 / 历史记录 / 管理）

## 🛠️ 技术特性

- 纯前端实现，无需后端服务
- 响应式设计，适配各种设备
- 本地存储，保护用户隐私
- 轻量级静态资源，无构建步骤
